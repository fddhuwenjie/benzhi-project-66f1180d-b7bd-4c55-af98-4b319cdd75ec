# 古树养护闭环核验台

古树养护闭环核验台是面向古树养护项目负责人、园林技术审核人员和现场执行人员的单流程 Web 应用。系统将任务建档、结构化现状采集、可解释风险评估、版本化方案编制、技术审核、现场实施证据与验收关闭串成一条可追溯时间线。

## 主要流程

1. 负责人创建养护任务；草稿资料可修订，但树木编号不可变，同一编号同时只能有一个未关闭任务。
2. 调查人员填写树冠、树干、根区和周边环境观测，并按部位登记照片、拍摄时间和说明。超过三十个自然日的观测可留档但不能评估。
3. 系统按树冠、树干、根区和环境稳定计算分组分值、等级与证据因子；无方案时可复核评估，人工降级受等级边界约束。
4. 编制人员把风险因子关联到措施、控制点和完成标准。低风险可说明不处置理由，高风险和重大风险必须覆盖。
5. 技术审核固定核验风险措施、材料适用性、作业窗口、安全控制和完成标准；驳回后的新版本必须逐项回应整改意见。
6. 批准后可连续登记不可变实施批次。负责人显式提交完工汇总后，系统核验措施、控制点、批次证据和待整改项。
7. 验收不通过时按完成标准生成稳定不符合项编号；后续批次关联整改和新证据，经完工汇总销项后方可复验。
8. 工作台支持关键词、责任人、状态、风险和期限分级组合查询，并按逾期、风险、期限及更新时间稳定排序。

所有写操作都使用 `request_id` 保证重复请求不重复执行，并通过 `revision` 进行乐观并发控制。关键决定和状态变化写入不可变审计事件。

## 构建

```bash
go build ./cmd/server
```

项目仅使用 Go 标准库，无需下载第三方依赖。

## 运行

```bash
go run ./cmd/server
```

默认地址为 `127.0.0.1:19081`，浏览器访问 `http://127.0.0.1:19081/`。可通过参数修改回环监听地址：

```bash
go run ./cmd/server -addr=127.0.0.1:19181
```

当 `PORT` 是有效端口号时，服务默认绑定 `127.0.0.1:<PORT>`；显式 `-addr` 会覆盖该默认值。服务拒绝 `0.0.0.0` 和外部网卡地址。持久化目录默认为 `./data`，可通过 `-data` 修改。

## 测试与自检

执行全部回归测试：

```bash
go test ./...
```

执行有界 HTTP 自检。该命令会实际启动临时服务，通过浏览器入口和 JSON API 完成从建档到验收关闭的完整流程，然后主动退出：

```bash
go run ./cmd/server -addr=127.0.0.1:19081 -selfcheck
```

## 数据与接口

聚合快照保存在 `data/snapshots/*.json`，审计事件以 JSON Lines 保存在 `data/audit/*.jsonl`。快照使用临时文件和原子替换提交，审计日志追加后执行同步；启动时会校验快照修订序列并修复不完整审计日志。

主要入口包括：

- `GET /`：浏览器工作台。
- `GET /healthz`：健康检查。
- `GET /api/cases`、`GET /api/cases/{id}`：任务台账、详情和时间线。列表支持 `keyword`、`owner_name`、`status`、`risk_level`、`deadline_level` 查询参数，并返回生效条件及多维统计。
- `POST /api/cases`：创建任务。
- `PATCH /api/cases/{id}`：修订草稿任务的位置、树种、责任人和期限。
- `POST /api/cases/{id}/survey`：提交结构化现状与照片证据。
- `GET|POST /api/cases/{id}/assessment`：预览自动评估或确认首次评估/复核。
- `POST /api/cases/{id}/plans`、`plans/submit`、`plans/review`：保存方案草稿、提交覆盖核验和技术审核。
- `POST /api/cases/{id}/executions`、`executions/complete`：登记实施批次和提交完工汇总。
- `POST /api/cases/{id}/acceptance`：提交验收、生成不符合项或复验关闭。
